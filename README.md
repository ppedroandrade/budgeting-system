# Orçamentos — Arte Decor Revest

Sistema web de orçamentos da Arte Decor Revest (Foz do Iguaçu – PR), substituindo a planilha Excel.

Stack: Next.js (App Router) + TypeScript + Tailwind · Supabase (Postgres, Auth, Storage, RLS) · @react-pdf/renderer · Vercel.

## Situação
- **Fase 1 — Base:** em andamento. Tokens de design em `src/styles/tokens.css` (prévia: `docs/tokens-preview.png`), aguardando aprovação.
- Logos em `assets/` (branca original + versão escura gerada para fundo claro e PDF).

## Rodar localmente
```bash
npm install
npm run dev
```
